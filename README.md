# Keystroke Biometrics

Biometric identification system based on typing patterns.

## Quick Start / Rýchly štart

### English

#### Requirements
- Python 3.x
- pip3

#### Run Options

**Option 1: Full Setup & Run (Recommended)**
```bash
./setup_and_run.sh
```
Interactive menu with options:
1. Run Backend only (API at http://localhost:5000)
2. Run Backend + Frontend (full system)
3. Run Backend + execute tests
4. Show project info
5. Exit

**Option 2: Run Backend Only**
```bash
./start_backend.sh
```
Starts Flask API server at http://localhost:5000

**Option 3: Run Frontend Only**
```bash
./start_frontend.sh
```
Starts HTTP server at http://localhost:8000  
⚠️ Make sure backend is running first!

#### Access
- Frontend: http://localhost:8000
- Backend API: http://localhost:5000/api
